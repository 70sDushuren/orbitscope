# OrbitScope 项目规划

> 版本 0.1 · 2026-11-16 · 状态:草案(待评审)

## 1. 项目愿景

用 Rust 构建一个**准实时**的近地轨道空间物体监视程序:定期从公开数据源获取全部已编目空间物体的轨道根数,
在本地用 SGP4 实时外推每个物体的位置,按**可配置的高度范围(默认 100–1000 km)**和**可配置的最小尺寸(默认直径 ≥ 10 cm)**
过滤,并以 3D 地球 / 2D 地图 / 列表 / 统计图等形式展示。

## 2. 关键事实与约束(决定了"实时"的含义)

| 事实 | 对设计的影响 |
|------|-------------|
| 公开数据源(Space-Track、CelesTrak)发布的是 **GP 轨道根数(TLE/OMM)**,而不是实时位置 | "实时位置" = 最新根数 + 本地 SGP4 外推。根数本身每几小时更新一次,位置每秒刷新 |
| 公开编目中**没有物体的物理尺寸**,只有雷达截面积 RCS(Space-Track 仅给 SMALL/MEDIUM/LARGE 三档;CelesTrak SATCAT 部分物体有数值 RCS,m²) | 尺寸过滤只能基于 **RCS → 等效直径的估算**,需明确标注"估算值",并为"未知尺寸"提供处理策略 |
| 美国空间监视网在 LEO 的常规编目门限约为 **10 cm** | 公开编目本身基本就是 "≥10 cm" 的物体集合;用户把门限调到 <10 cm 不会得到更多物体(文档和 UI 中需说明) |
| Space-Track 需要免费注册账号,且有调用频率限制(约 30 次/分、300 次/时,GP 全量建议 ≤ 1 次/小时) | 必须本地缓存 + 调度器限速;账号密码只放环境变量/本地配置,绝不入库 |
| CelesTrak 无需账号,但公开分组不含全部碎片,且对重复下载有封禁策略 | 作为默认/免注册数据源与 SATCAT 元数据来源;尊重其更新周期,不重复下载未更新的数据 |
| 全编目约 3 万个在轨编目物体,其中 LEO 占大多数 | SGP4 单次外推为微秒级,3 万物体每秒全量外推在单核上也 < 100 ms,性能不是瓶颈;数据传输与前端渲染才是 |

## 3. 范围

### 3.1 v1.0 范围内
- 数据获取:Space-Track(全量,需账号)、CelesTrak(免账号)、本地 TLE/OMM 文件导入
- 本地缓存与离线运行
- SGP4 外推、TEME → ECEF → WGS84 大地坐标转换
- 过滤:高度范围(轨道近/远地点 + 瞬时高度两种模式)、最小尺寸、物体类型、国家/所有者、名称/编号搜索
- 展示:Web 3D 地球(浏览器打开)、物体列表、单物体详情与地面轨迹、统计面板
- CLI:抓取、查询、导出(CSV/JSON)、启动服务
- 可配置:配置文件 + 命令行 + 运行时 UI 修改过滤条件

### 3.2 v1.0 范围外(列入后续路线图)
- 碰撞/接近分析(conjunction screening)
- 观测者过境预报(某地何时可见)
- 再入预报
- 原生桌面 3D 客户端(Bevy/egui)
- 前端 WASM 本地外推
- 历史回放(依赖 gp_history,受 Space-Track 严格限制)

## 4. 里程碑

| 里程碑 | 内容 | 交付物 / 验收标准 |
|-------|------|------------------|

| M7+(可选) | 过境预报、接近分析、WASM 外推、TUI、桌面客户端 | 视需求排期 |

## 5. 风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| 尺寸数据不足/不准(RCS 仅分档或缺失) | 尺寸过滤结果不精确 | 明确标注"估算";提供"未知尺寸:包含/排除"开关;数值 RCS 优先,分档次之 |
| 数据源接口/策略变化 | 抓取失败 | 数据源抽象为 trait;缓存兜底;启动时校验并报告 |
| 被数据源限流/封禁 | 无法更新 | 内置限速器、遵守更新周期、条件请求、错峰调度、指数退避 |
| TLE 过期导致外推误差大 | 位置错误 | 记录 epoch 龄期,超过阈值(默认 14 天)标记/剔除;UI 显示数据龄期 |
| 前端渲染大量点卡顿 | 体验差 | 二进制帧 + 前端插值 + Cesium PointPrimitiveCollection;可降频 |
| 凭据泄露 | 账号安全 | 凭据只从环境变量/不入库的本地文件读取;日志脱敏 |

## 6. 技术选型摘要

- 语言/工具链:Rust stable(2024 edition),Cargo workspace
- 外推:`sgp4` crate(纯 Rust,支持 OMM JSON)
- 异步/网络:`tokio`、`reqwest`(rustls)、`axum`(HTTP + WebSocket)
- 并行:`rayon`
- 序列化/配置:`serde`、`serde_json`、`toml`、`csv`
- CLI:`clap`;日志:`tracing`;错误:`thiserror`(库)/ `anyhow`(二进制)
- 时间:`chrono`(UTC)
- 前端:CesiumJS(使用其自带离线 NaturalEarthII 影像,无需 Cesium ion token)+ 原生 TypeScript/JS,无重型框架

详细理由见 [03-design.md](03-design.md) 中的架构决策记录(ADR)。
